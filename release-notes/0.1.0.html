Lamba 0.1

The first release

  • Your MagSafe LED as a status light: green, orange, blinking or off, from the menu bar, the command line or Claude.
  • Pomodoro: click the clock in the Dock to start. The keyboard backlight dims while you focus and breathes during breaks.
  • An optional Dock made of islands, with contexts (Work, Personal, Presenting) that change your apps, wallpaper and appearance.
  • Claude Code sessions on this Mac and your servers, with permission requests right in the Dock.
  • Updates install automatically from now on.
