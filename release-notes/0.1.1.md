A small fix release.

## Fixed

- **Settings:** clicking a page in the sidebar now opens it. Before, the window stopped redrawing after it opened, so the sidebar seemed to do nothing.
- **Never sleep:** the switch now reads the Mac's sleep state in the background, so Settings and the menu bar panel never wait on it.

## Install or update

Lamba 0.1.0 updates itself; you can also choose **Check for Updates…** in the menu bar menu.

```sh
brew install --cask productdevbook/tap/lamba
```

Or download **Lamba.dmg** below.
